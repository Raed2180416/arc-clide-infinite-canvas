# ARC / CLIDE Infinite Canvas

An interactive, read-only map of the ARC/CLIDE system and its dynamic end-to-end runtime graph.

## Open the canvas

The published site is the repository's [`index.html`](./index.html). It has three switchable views:

- **A — system planes:** architecture and authority boundaries first.
- **B — causal river:** ingress through intent, evidence, graph control, authoring, evaluation, effects, and completion.
- **C — module universe:** the complete measured module/catalogue graph with imports and runtime slots.

Drag to pan, wheel to zoom, search any component or event, inspect neighbors, reveal implementation files, and materialize an example task graph. The canvas is read-only and has no persistence or authority; EventKernel and TaskRuntime remain the intended durable controllers.

## Snapshot

This checkpoint contains 2,996 measured nodes and 6,189 relationships: 204 architecture organs, 2,171 files, 58 TaskEvent types, 430 levers, 19 model routes, 40 model artifacts, 57 domains, seven memory stores, and ten runtime graph slots.

The graph is a snapshot of the ARC checkout at generation time. It records the committed HEAD plus the live working-tree overlay, including any concurrent in-progress paths. It is not a claim that the source checkout is clean or that every product capability is already proven.
